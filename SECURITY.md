# Seguridad

## Versiones soportadas

| Versión                                    | Soporte                                        |
| ------------------------------------------ | ---------------------------------------------- |
| 0.1.x                                      | Correcciones de seguridad desde su publicación |
| Ramas de desarrollo y versiones anteriores | Sin garantía de soporte                        |

## Reportar una vulnerabilidad

Use [Report a vulnerability](https://github.com/alezdut/glucosapp/security/advisories/new) de GitHub para informar de forma privada al mantenedor. No publique vulnerabilidades pendientes ni datos de pacientes en issues. Si el formulario no está disponible, no publique detalles sensibles: use el contacto público del perfil del mantenedor para solicitar un canal privado.

Incluya versión o commit, componente, impacto y reproducción mínima con cuentas y datos ficticios. No pruebe contra instalaciones ajenas. El mantenedor coordinará evaluación y publicación de una corrección; este proyecto no promete tiempos de respuesta ni servicio de emergencia.

## Alcance experimental

Glucosapp y su algoritmo MDI no están validados clínicamente. Las cuentas y claves de la demo son exclusivamente locales. No exponga la demo a Internet ni cargue datos reales. Para evaluar el algoritmo use escenarios sintéticos y revisión profesional.
